# Hide Quiver — *Dark Souls III*

Equipping a bow or crossbow no longer puts a quiver, bolt case, or the arrows inside them on your character.
Bow and crossbow stats, damage, stamina cost, weight and saves are untouched.

This is a set of 39 replacement `parts` models — 78 `.partsbnd.dcx` files, each model plus its `_l` LOD twin.
No DLL, no param edits.

## Models replaced

- Arrow quiver: `wp_a_6399`
- Bolt case: `wp_a_6700` (male), `wp_a_9700` (female)
- Arrows: `wp_a_7000` – `7071`
- Greatarrows: `wp_a_7300` – `7331`
- Bolts: `wp_a_7600` – `7661`

## Install

- The `parts` folder in this repository is the whole mod — 78 files, flat, no subfolders. Copy it where your loader reads loose files: point one of [me](https://www.nexusmods.com/darksouls3/mods/2410), [me2](https://github.com/soulsmods/ModEngine2), or [me3](https://github.com/garyttierney/me3).
- Or copy the files into `Game\parts\` on a game unpacked with UXM / Nuxe, keeping a copy of the originals. Models are read at startup, so restart the game if it was running.
